# wechat-chat-to-html

把本机微信（Windows / 微信 4.x）里某个联系人或群聊的**聊天记录导出成可浏览的 HTML**，
内嵌**真实表情包图片**与**语音播放器**，同时产出 Markdown / 纯文本 / 原始日志。

> 起因：`wechat-cli export` 在微信 4.x 上只能输出 `[表情]` `[语音]` `[图片]` 占位符。
> 因为 4.x 把语音以 SILK BLOB 内联进数据库、把表情包用私有格式（AES + 自定义 HEVC 容器）
> 散在缓存目录里。这个项目把这两类内容真正还原出来，再拼回一条时间线。

## ⚠️ 隐私声明（请务必先读）

这个工具处理的是**解密后的私人聊天数据**，敏感度等同于你的微信本体。使用和分享时请注意：

1. **导出产物绝不能进仓库。** 导出目录里的 `<对方>_聊天记录.*`、`<对方>_聊天记录_媒体/`
   是**原文聊天内容**（含图片、语音）。仓库里已带一份 `.gitignore` 拦截这些路径，
   但**不要**依赖它——提交前自己 `git status` 看一眼。
2. **密钥文件绝不能外传。** `~/.wechat-cli/all_keys.json`（数据库密钥）与
   `~/.wechat-cli/emoji_key.json`（表情 AES 密钥，由本工具生成）都是**该账号专属**的机密。
   它们能解开你本机的微信数据，泄露即等于把聊天记录交出去。
3. **中间产物是明文数据库。** 解密后的库落在 `%TEMP%\wxchat_work\<wxid>\`，
   导出完请自行清理，不要整个 temp 目录打包分享。
4. **只处理你有权访问的数据。** 本项目用于导出**你自己设备上、你自己账号**的聊天记录。
   请勿用于未授权访问他人数据；使用时请遵守当地法律法规与微信的服务条款。
5. **导出前会先问用户要存到哪个文件夹**，请认真挑一个自己放心的位置，
   不要放到会自动同步/共享的目录（网盘同步区、共享盘、被备份的目录）。

## 功能

- 从本机微信数据库重建会话时间线（自动处理跨库分片、发送人归属）
- 还原**表情包**：AES-128-CBC（IV = Key）解密 → PNG / GIF / WEBP / JPG，私有 `wxgf`（HEVC）容器也能解
- 还原**语音**：SILK → 24kHz WAV，可直接在浏览器里播放
- 识别引用、文件、链接、小程序、位置、转账红包、撤回等系统消息
- 输出一份自带**全文搜索、类型筛选、日期跳转**的 HTML 阅读页

## 输出

```
<存放文件夹>/
├── <对方>_聊天记录.html        主交付物：表情贴图 + 语音播放器 + 搜索/筛选
├── <对方>_聊天记录.md
├── <对方>_聊天记录.txt
├── <对方>_聊天记录_raw.md      一行一条的原始日志（供二次处理）
└── <对方>_聊天记录_媒体/
    ├── 表情/                   去重后的表情包图片
    ├── 语音/                   可直接播放的 WAV
    └── *.json                  manifest
```

HTML 与媒体文件夹靠**相对路径**绑定：要挪就整份一起挪，别只挪 HTML。
HTML 直接双击打开看不到图/听不到声音，需要在本目录起个静态服务：

```bash
python -m http.server 8770 --bind 127.0.0.1
# 然后访问 http://127.0.0.1:8770/<对方>_聊天记录.html
```

## 前置要求

1. Windows + 微信 4.x，账号在本机登录过（数据在 `xwechat_files/<wxid>_xxxx/db_storage`）
2. 已用 `wechat-cli` 提取过数据库密钥
   （`~/.wechat-cli/config.json` + `~/.wechat-cli/all_keys.json` 存在）
3. 依赖：`wechat-cli pycryptodome pysilk av Pillow zstandard`（详见 `references/环境与依赖.md`）
4. 想还原表情包时，微信需处于**运行状态**（表情密钥只在进程内存里）

## 用法

```bash
# 0) 先确定存到哪个文件夹（技能会主动问你）
# 1) 确认是哪个联系人（同名会有多个，★ 为精确匹配）
python scripts/wxchat_export.py list --name 张三

# 2) 一键导出
python scripts/wxchat_export.py all --name 张三 --out "D:\备份\张三_聊天记录"

# 3) 自检：4 个文件是否齐、媒体引用是否都能落到磁盘
python scripts/verify_export.py "D:\备份\张三_聊天记录"
```

也可以拆步跑（适合大聊天或中断续跑）：`db` / `emojikey` / `voice` / `stickers` / `build`。

常用参数：`--peer-username`（直接指定 wxid，跳过名称匹配）、`--me`（「我」的显示名）、
`--backfill`（外部 raw.md 回填）、`--force`（覆盖已存在的同名产物）、
`--no-voice` / `--no-stickers`（跳过对应步骤）。

## 已知局限

- **图片（`local_type=3`）仍是 `[图片]` 占位**：4.x 的 `.dat` 图片用另一把 AES 密钥，
  且该密钥只在「浏览过图片之后」才进内存。需要先让微信实际打开过这些图片再扫内存。
- 群聊里除对方外的成员昵称未做补全，会显示 wxid。
- 极少数表情（HEVC 解码异常）会保留原始 `.wxgf` 文件，HTML 里显示为占位符。
- 只能导出本机库里已有的消息；手机端独有历史需先用微信「迁移」到电脑。
