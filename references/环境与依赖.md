# 环境与依赖

## 解释器

技能脚本不绑定解释器，但**必须**用装了下列依赖的那个 Python。下面统一记作 `<PY>`。

建议单独建一个 venv，避免和你系统里其它 Python 混淆：

```bash
python -m venv <你的 venv 路径>
<你的 venv 路径>/Scripts/pip install pycryptodome pysilk av Pillow zstandard
```

**常见坑**：一台机器上往往有多个 Python（系统自带、pyenv/conda、各种托管运行时）。
只有你 `pip install` 过上面这些包的那个才可用，其余会直接 ImportError。装完后用下面的自检命令
确认到底是哪一个：

```bash
<PY> -c "import wechat_cli.core.crypto, Crypto, pysilk, av, PIL, zstandard; print('deps ok')"
```

## 依赖清单

| 包 | 用途 |
| --- | --- |
| `wechat-cli` | 提供 `wechat_cli.core.crypto.full_decrypt / decrypt_wal`（SQLCipher 4 解密） |
| `pycryptodome` | 表情 AES-128-CBC（`from Crypto.Cipher import AES`） |
| `pysilk` | SILK → 24kHz PCM（语音） |
| `av` (PyAV) | 解 wxgf 里的 HEVC 码流 |
| `Pillow` | GIF 帧数统计、多帧转自适应调色板 GIF |
| `zstandard` | 解 `WCDB_CT_message_content=4` 的压缩消息体 |

`wechat-cli` 按它自己的安装方式装即可，本技能只用到它的解密模块。

镜像注意：部分国内镜像（如清华 `pypi.tuna.tsinghua.edu.cn`）偶有包缺失，报
`No matching distribution found (from versions: none)` 时加 `-i https://pypi.org/simple` 走官方源。

## 依赖的本机文件

| 路径 | 内容 |
| --- | --- |
| `~/.wechat-cli/config.json` | `db_dir` 指向 `<xwechat_files>/<wxid>_xxxx/db_storage` |
| `~/.wechat-cli/all_keys.json` | 各库 `enc_key`（裸密钥，**不需要**再跑 PBKDF2） |
| `~/.wechat-cli/emoji_key.json` | 本技能缓存的表情 AES 密钥（按 wxid 分条，**含个人密钥，不要外传**） |

## 中间产物位置

解密后的数据库默认落在 **系统临时目录**（`%TEMP%\wxchat_work\<wxid>\`），
不进用户指定的交付文件夹——交付目录只应包含 4 个文件 + 1 个媒体文件夹。
想换位置传 `--workdir`；确认不需要了可以直接删掉整个 `%TEMP%\wxchat_work` 目录。
`_wxchat_summary.json`（本次导出的统计）也写在那个目录里。

> 注意：`%TEMP%\wxchat_work\` 里是**解密后的原始聊天数据库**，属于敏感数据。
> 导出完可以随时清掉；不要把整个 temp 目录打包分享。
